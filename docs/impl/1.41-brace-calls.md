  $0, object → named spread, array → positional, empty → no args), resolved

  rule-19 `$sh` suffix). `sh` and `pw` become builtin components — always

  E007 reserved names. Arbitrary backend names are no longer callable syntax

# 1.41 — Brace calls, `$<name>` key suffix, and `sh`/`pw` as builtin components

## Task 1: Builtin components `sh` / `pw` (ymx-core)

- [ ] 1.1 Register `sh`/`pw` as builtin component defs in the global namespace (virtual defs — always present, no file)
- [ ] 1.2 Body semantics: render `$0` to text (Object/Array `$0` → E011) and execute via `Options.executor`; result `{exit_code, stdout, stderr}`; non-zero exit is a result, not an error
- [ ] 1.3 E016 paths preserved: no executor, disallowed by `allowed_backends`, spawn failure
- [ ] 1.4 Callable via every form: `from: sh`, rule-8 shortcut (`sh: <cmd>`), `$sh(...)` parens, `$sh{...}` braces (Task 4), math `sh(...)`
- [ ] 1.5 Reserved names: add `sh`/`pw` to the load-time E007 check (all leading-`$` variants); collisions with user/imported/`-c` definitions → E007
- [ ] 1.6 Empty args (`$sh{}` / `$sh()`) → E003 in `sh`'s body; `$sh{""}` runs an empty command

### Acceptance criteria

- [ ] `from: sh` + `0: echo hi` → `{exit_code: 0, stdout: "hi\n", stderr: ""}`
- [ ] Rule-8 shortcut `sh: echo hi` → same
- [ ] `$sh(echo hi)` (parens) → same
- [ ] Defining `sh:` / `$sh:` / `pw` → E007 at load (crate unit test — load-time, not `_test`-driveable)
- [ ] Executor `None` → E016; `allowed_backends: [sh]` blocks `pw` → E016

## Task 2: Scanner — generalized brace-call segment (ymx-core, interp.rs)

- [x] 2.1 Generalize `Segment::Exec` → a single brace-call segment `{ name, payload_src, span }` for all `$name{...}` forms
- [x] 2.2 Balanced, quote-aware payload capture (reuse callsite.rs tracking) — fixes `$sh{awk '{print $1}'}` truncation at the first `}`
- [x] 2.3 `${...}` math scan unchanged (first `}`); `$name(...)` and `$N` paths unchanged

### Acceptance criteria

- [ ] `$b{40}` scans to a brace-call segment (name=b, payload="40")
- [ ] `$b{{c: 1, d: 2}}` captures the balanced object payload
- [ ] `$sh{awk '{print $1}'}` captures the full command
- [ ] Unterminated brace call → E010

## Task 3: Payload parser (ymx-core, callsite.rs)

- [ ] 3.1 Inline object-literal parser: `{k: v, …}` — identifier keys only (else E010), values per the argument-value grammar, nested literals allowed
- [ ] 3.2 Array-literal parser: `[v0, v1, …]`
- [ ] 3.3 Scalar payload: parse per the argument-value token grammar (null/bool/int/float/string, quotes)
- [ ] 3.4 Malformed payload (non-identifier key, unbalanced literal) → E010

### Acceptance criteria

- [ ] `{c: 1, d: 2}` → named args c=1, d=2
- [ ] `[1, 2]` → positional $0=1, $1=2
- [ ] `40` → Int 40; a quoted token → String with commas/braces preserved
- [ ] `{a-b: 1}` → E010

## Task 4: Resolver — brace-call evaluation + key suffix (ymx-core, resolve.rs / project.rs)

- [ ] 4.1 Brace call runs in rule-11 step 1 (inline call), bottom-up; consumes a depth slot (E008)
- [ ] 4.2 Resolve the payload in the enclosing scope before binding (nested `$name` / `${...}` / calls)
- [ ] 4.3 Binding table: scalar → `$0`; object → named spread; array → positional; empty → no args
- [ ] 4.4 Target: single effective identifier; namespace lookup (declared/imported/builtin component); templates not valid; unknown → E002 (special-form names → E002 with paren hint)
- [ ] 4.5 Callee is an ordinary component call (template chain, `from`, `?:` merge all compose)
- [ ] 4.6 Native type when the brace call is the entire property value; rendered per Number→string when embedded in text (Object/Array → E011)
- [ ] 4.7 Generalize the `$<name>` suffix (currently backend-only `exec_backend`) on **property keys and component/template names** to a component call target: `a$<name>: v` ≡ `a: $<name>{v}` (value = YAML node payload); `?$<name>` combo; wrong order `$<name>?` → E010
- [ ] 4.8 Extend suffix-variant lookups (`locate_definition`, `resolve_entry`) to `$<name>` and `?$<name>`; same-base suffix defs (`a$b:` + `a$c:`, `a$b:` + `a$:`) → E004 (crate unit test — load-time)
- [ ] 4.9 Remove backend routing from brace-call resolution; the E016 UnknownBackend path becomes unreachable via syntax (keep or drop the variant; StdExecutor unchanged)
- [ ] 4.10 `$name{...}` inside `$sh{...}` command strings resolves in the enclosing scope (composes with 1.31's `$name(args)`)

### Acceptance criteria

- [ ] `main: $a{40}` + `a$: $0 + 1` → 41
- [ ] `a$b:` with mapping payload → named spread (`b$: c + d` → `main` = `{a: 3}`)
