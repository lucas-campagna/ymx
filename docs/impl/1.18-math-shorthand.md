  Implement the `$` property-key modifier (rule 18): `<name>$: <src>` is exactly
  equivalent to `<name>: ${<src>}`. The value must be a String math source.
  Also covers: `$` on integer keys (`0$:` ⇒ math source for slot `$0`), `$` on
  component/template names (`a$: x + y` ≡ `a: ${x + y}`), and combination
  `?$` (`<name>?$: <src>` ≡ `<name>?: ${<src}` — optional with math-evaluated
  default). Wrong order `$?:` is E010.

> **Partial implementation note (2026-08-18):** The top-level component-name `$` modifier
> (e.g. `sum$: x + y` ≡ `sum: ${x + y}`) was **not** implemented in this milestone.
> The implementation handles property-key `$` shorthand only. The spec (PRD line 445)
> documents that top-level `a$: src` should work, but the current implementation rejects
> top-level `$`-suffixed keys with "invalid top-level name". Milestone **1.26** covers
> fixing this gap.
