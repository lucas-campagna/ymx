description: |
  Add a `-c` / `--code <yml>` CLI flag that accepts inline YAML or JSON
  component definitions. Four usage modes: (1) `-c` only (no file) — the
  inline content is the script; (2) file + `-c` — load the file, then overlay
  `-c` components (complete replacement on name collision); (3) stdin-args +
  `-c` — `-c` is the script, stdin provides call arguments; (4) file +
  stdin-args + `-c` — load file, overlay `-c`, stdin provides call args.
  `-c` does not contribute `_ymx` / `_test` metadata. Combined with `--test`
  is a usage error (exit 2).
status: planned

# 1.28 — CLI inline code flag (`-c`)

## Tasks

- [x] `ymx-core`: add `NamespaceStore::register_override` — like `register` but
  replaces an existing definition in the same namespace without E004 error
- [x] `ymx-lib`: add `load_project_with_override(root, override_yaml: Option<&str>)`
  — loads the project normally, then parses `override_yaml` as a YAML document
  and registers its top-level key-value pairs as global-namespace components via
  `register_override`. Discards `_ymx` / `_test` / file-scoped definitions from
  the override. Reuses existing `load_project` internals (no code duplication)
- [ ] `ymx-cli/args`: add `code: Option<String>` to `ParsedCli`; recognize
  `-c` / `--code` in the parser (take next arg as value); reject `-c` with
  `--test` as a parse error (exit 2)
- [ ] `ymx-cli/run`: wire `-c` into the pipeline — four branches:
  1. `-c` only (no file): write `-c` to temp `main.yml`, load, entry = `main.main`
  2. file + `-c`: `load_project_with_override(path, Some(code))`, entry from file stem
  3. stdin-args + `-c`: same as (1) but read stdin as call args
  4. file + stdin-args + `-c`: same as (2) but read stdin as call args
- [ ] `ymx-cli/help`: add `-c, --code <yml>` to manual page with examples
- [ ] `docs/PRD.md`: add `-c` to CLI flags section with semantics and examples
- [ ] Unit tests: `-c` arg parsing, override merge (file + `-c`), `-c` only mode,
  stdin-args + `-c`, `-c` + `--test` rejection

## Acceptance

- [ ] `ymx -c 'main: hello world'` prints `"hello world"`
- [ ] `ymx -c '{"main": "${1 + 1}"}'` prints `2`
- [ ] `echo '{"a": 1, "b": 2}' | ymx -c "main$: a + b"` prints `3`
- [ ] `echo -e 'a: 10\nb: 22' | ymx -c '{"main": "${a + b}"}'` prints `32`
- [ ] Given `a.yml` with `comp1$: a + b` / `comp2$: $comp1(a=$x,b=$y)`:
  `ymx a.yml -c 'main: $comp2(x=2,y=3)\ncomp1$: a * b'` prints `6`
- [ ] `-c` components override file components with the same name (complete replacement)
- [ ] `-c` + `--test` → exit 2 (usage error)
- [ ] `cargo fmt && cargo clippy --workspace --all-targets` clean
- [ ] `cargo test --workspace` passes
