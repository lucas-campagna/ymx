# 1.7 — Array templates (rules 12–14)

## Tasks

- [ ] Rule 12 — `$a` non-array, `a` array -> map: each item through `$a`; output array
- [ ] Rule 13 — `$a` array, `a` non-array (object initializer) -> reduce:
  - [ ] Iterate `$a` items; initial args from `a`
  - [ ] Each step: previous result overwrites initial **only for keys it actually returns**, **only for the immediately-next step**; non-object result -> no overwrite, revert to initial
  - [ ] `$last`/`last` available from step 2 onward (step 1 ref -> E003)
- [ ] Rule 14 — both arrays -> rule-13 reduce applied independently to each element of `a`; result array of reduced entries
- [ ] Edge cases (lenient):
  - [ ] Empty `a` -> empty array
  - [ ] Empty `$a` -> pass-through (input unchanged)
  - [ ] Non-array `$a` over non-array `a` -> rule-5 call with `a` as `$0`
  - [ ] Array `$a` over non-array `a` (scalar/object) -> single-element reduce (object = initial args; scalar binds `$0`)
  - [ ] Mixed-shape within a chain (array link in non-array chain) -> E010 (matches 1.6 mixed-shape rule)
- [ ] Wire `$last` into reduce step scope (math `last` + string `$last`); E003 on first step / outside reduce

## Acceptance
- [ ] Scenario: rule-12 example -> `[{prop1,prop2}, ...]`
- [ ] Scenario: rule-13 example -> `"1 + 2 < 6"` (overwrite-then-revert + `$last`)
- [ ] Scenario: rule-14 example -> `[{"a":1,"b":4,"sum":5}, {"a":3,"b":8,"sum":11}]`
- [ ] Scenarios for all four edge cases
- [ ] Unit: `$last` on first step -> E003
