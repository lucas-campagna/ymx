# 1.2 — Core IR & diagnostics types

- [ ] `ir::Value` enum: `Null | Bool(bool) | Int(i64) | Float(f64) | String(String) | Array(Vec<Value>) | Object(IndexMap<String, Value>)`
  - [ ] `#[derive(Debug, Clone, PartialEq)]` + `serde::Serialize` with insertion-order object keys
  - [ ] Helper constructors + `Value::is_scalar`/`is_object`/`is_array`

- [ ] `Options { entry, from_keyword, default_keyword, max_depth, pretty, format, plain }` + `Default` impl (entry=`"main.main"`, `max_depth=256`, `format=Json`, `plain=False`)

- [ ] `enum PlainMode { False, All, TemplatesOnly }`
