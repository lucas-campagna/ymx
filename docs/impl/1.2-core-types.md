# 1.2 — Core IR & diagnostics types

## Tasks

- [x] `ir::Value` enum: `Null | Bool(bool) | Int(i64) | Float(f64) | String(String) | Array(Vec<Value>) | Object(IndexMap<String, Value>)`
  - [x] `#[derive(Debug, Clone, PartialEq)]` + `serde::Serialize` with insertion-order object keys
  - [x] Helper constructors + `Value::is_scalar`/`is_object`/`is_array`
- [x] Single shared f64 renderer (`ir::render_f64`) for JSON output + string interpolation
  - [x] Integer-valued floats keep fractional part (`2.0` -> `"2.0"`) via ryu
  - [x] Document that `{}` formatting is NOT used
- [x] `diag::Diagnostic { file: Option<PathBuf>, line, col, component: Option<String>, code: &'static str, message }`
  - [x] `render(&self) -> String` -> `"[code] file:line:col (component): message"` (file omitted/`<?>` when `None`)
- [x] `diag::FileId(pub u32)`, `diag::Span { line: u32, col: u32 }`
- [x] `Options { entry, from_keyword, default_keyword, max_depth, pretty, format, plain }` + `Default` impl (entry=`"main.main"`, `max_depth=256`, `format=Json`, `plain=False`)
- [x] `enum Format { Json, Diagnostics }`
- [x] `enum PlainMode { False, All, TemplatesOnly }`
- [x] `Project { files: Vec<PathBuf>, namespaces, file_scoped, raw_meta_ymx: Vec<(FileId, Value)>, raw_meta_test: Vec<(FileId, Value)> }` (fields left TODO-private for 1.3 to fill)
- [x] `Args { None, Named, Positional, Mixed }` + `TestArgs` mirror in ymx-test? (TestArgs lives in ymx-test; here only `Args`)
- [x] Error code constants `E001..E013`, `E015` as `&'static str`

- [x] Unit test: `Diagnostic::render` format matches PRD exactly
