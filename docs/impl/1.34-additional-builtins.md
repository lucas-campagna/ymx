## Tasks

### String builtins (all eager args)

- [x] `$split(str, delim)` — str and delim both String → Array<string>; delim empty string → E011
- [x] `$join(arr, delim)` — arr must be Array, delim must be String → string; empty array → empty string
- [x] `$trim(str)` — str must be String → string with leading/trailing whitespace removed
- [x] `$upper(str)` — str must be String → uppercase string
- [x] `$lower(str)` — str must be String → lowercase string
- [x] `$replace(str, pattern, replacement)` — all args String; replaces all occurrences of pattern with replacement (no regex); result is string

   All string-builtin args (str, delim, pattern, replacement) support passing a component
   reference `$name` in addition to literal values; the reference is resolved through the
   caller's scope before use.

### Array builtins (all eager args, arr must be Array unless noted)

- [x] `$filter(fn, arr)` — first arg unevaluated callable (like $map/$reduce), second arg eager Array; keeps items where fn returns truthy; truthy = Bool(true) or non-Null/non-false non-bool; empty → empty array; array item → E011 (same as $map)
- [x] `$sort(arr)` — arr must be Array of numbers or strings; returns sorted copy, stable order; non-homogeneous or non-comparable → E011
- [x] `$reverse(arr)` — arr must be Array; returns reversed copy
- [x] `$unique(arr)` — arr must be Array; returns new array with first occurrence of each value kept (equality via Value::eq); preserves order
- [x] `$flatten(arr)` — arr must be Array; one level of flattening: each array element is spliced in-place, non-array elements remain
- [x] `$first(arr)` — arr must be Array → first element or Null if empty
- [x] `$last(arr)` — arr must be Array → last element or Null if empty
- [x] `$slice(arr, start, end)` — arr must be Array, start and end are Int; end is exclusive; negative indices count from end; clamped to bounds; returns subarray

   The arr argument supports passing a component reference `$name` in addition to a literal
   array; it is resolved through the caller's scope. Builtins with callable args ($filter, $when)
   additionally accept a bare component name as the callable.

### Object builtins (all eager args, obj must be Object unless noted)

- [x] `$keys(obj)` — obj must be Object → Array<string> (preserves key insertion order)
- [x] `$values(obj)` — obj must be Object → Array (preserves value order matching keys)
- [x] `$entries(obj)` — obj must be Object → Array<Object> where each entry is `{key: <k>, value: <v>}`
- [x] `$from_entries(arr)` — arr must be Array of objects each with `key` (string) and `value` fields; returns Object assembled from entries (later entries overwrite earlier on duplicate keys)
- [x] `$pick(obj, keys)` — obj must be Object, keys must be Array<string>; returns new object with only the listed keys (key not present → skipped)
- [x] `$omit(obj, keys)` — obj must be Object, keys must be Array<string>; returns new object without the listed keys

   The obj argument supports passing a component reference `$name` in addition to a literal
   object; it is resolved through the caller's scope.

### Type checking / coercion (all eager args)

- [x] `$type(val)` — val any Value → string: `"null" | "bool" | "int" | "float" | "string" | "array" | "object"`
- [x] `$is_array(val)` — val any Value → bool
- [x] `$is_object(val)` — val any Value → bool
- [x] `$is_string(val)` — val any Value → bool
- [x] `$is_number(val)` — val any Value → bool (Int or Float)
- [x] `$is_null(val)` — val any Value → bool
- [x] `$to_string(val)` — val any Value → string (same rendering as interpolation, including numbers)
- [x] `$to_number(str)` — str must be String → parses numeric string → Int or Float, or Null if not parseable

   All type-builtin args support passing a component reference `$name` in addition to a
   literal value; the reference is resolved through the caller's scope.

### Aggregate math (all eager args, arr must be Array of numbers)

- [x] `$sum(arr)` — arr must be Array of numbers (Int/Float); empty → 0
- [x] `$avg(arr)` — arr must be Array of numbers; empty → Null
- [x] `$min(arr)` — arr must be Array of numbers; empty → Null
- [x] `$max(arr)` — arr must be Array of numbers; empty → Null

   The arr argument supports passing a component reference `$name` in addition to a literal
   array; it is resolved through the caller's scope.

### Conditional builtins

- [x] `$if(cond, then, else)` — cond must be Bool; returns then if true, else if false; only the selected branch is evaluated (lazy semantics); the unselected branch is never evaluated
- [x] `$if` property-call syntax: `if: <cond>\n  then: <then_val>\n  else: <else_val>` — only `if`/`then`/`else` property keys allowed; any other key → E010
- [x] `$when(fn, arr)` — first arg unevaluated callable, second arg eager Array; applies fn to each item and keeps it if result is truthy (same truthy rule as $filter); result is Array of kept (transformed) items

   The cond/then/else args support passing component references; then/else in $if are
   lazily evaluated (only the selected branch's component is invoked).

## Acceptance criteria

### String builtins
- [x] `$split("a,b,c", ",")` → `["a","b","c"]`
- [x] `$split("hello", "")` → `["h","e","l","l","o"]`
- [x] `$split("a::b::c", "::")` → `["a","b","c"]`
- [x] `$split("abc", ",")` → `["abc"]` (no match → single-element array)
- [x] `$split("a,b", "")` → E011 (empty delimiter)
- [x] `$join(["a","b","c"], "-")` → `"a-b-c"`
- [x] `$join([], "x")` → `""`
- [x] `$join(["hello"], "")` → `"hello"`
- [x] `$trim("  hello  ")` → `"hello"`
- [x] `$trim("hello")` → `"hello"` (no whitespace → unchanged)
- [x] `$upper("hello")` → `"HELLO"`
- [x] `$lower("HELLO")` → `"hello"`
- [x] `$replace("hello world", "world", "rust")` → `"hello rust"`
- [x] `$replace("aaaa", "a", "b")` → `"bbbb"` (all occurrences)
- [x] `$replace("abc", "x", "y")` → `"abc"` (no match)

### Array builtins

- [x] `$reverse([1,2,3])` → `[3,2,1]`

- [x] `$flatten([[1,2],[3,[4]]])` → `[1,2,3,[4]]` (one level only)
