version: "1.35"
title: "HTML renderer"
short: "Rule 20: HTML renderer — recursive inner-first rendering, style/class normalization, attribute handling"
description: |
  Implements the HTML renderer: a second pass over the resolved Value IR that
  produces an HTML string. Renders from/children recursively (inner-first), handles
  style (string | CSS-object → "key: value; ...") and class (string | array | truthy-object → space-joined), and emits all other object keys as HTML attributes with proper boolean-attr and empty-value omission.
status: planned
depends_on: ["1.34"]
tags: [html, renderer, milestone]
---
