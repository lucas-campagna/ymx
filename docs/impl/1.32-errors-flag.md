# 1.32 — CLI `--errors` flag

## Tasks

- [x] New `errors.rs` module in `ymx-cli` with the formatted diagnostic code table
  - [x] `ERROR_TABLE` constant containing the full table (code, stage, short description)
  - [x] `pub fn print_errors()` that prints the table to stdout
- [x] Arg parser (`args.rs`): add `errors: bool` to `ParsedCli`
  - [x] Parse `--errors` as a standalone flag (no value)
  - [x] Return `ParseOutcome::Errors` when `--errors` is seen
  - [x] No positional required when `--errors` is given (like `--help`)
  - [x] Reject `--errors` combined with `--test`, `-c/--code`, `--output`, `--entry`, `--format` (CLI usage error, exit 2)
- [x] `ParseOutcome` enum: add `Errors` variant
- [x] `main.rs`: handle `ParseOutcome::Errors` — print table, exit 0
- [x] `help.rs`: add `--errors` to `EXPECTED_FLAGS` and `MANUAL` string
- [x] Unit tests for arg parsing (`--errors` alone, `--errors` with file, `--errors` with conflicting flags)

## Acceptance

- [x] `ymx --errors` prints the diagnostic code table to stdout and exits 0
- [x] `ymx --errors some_file.yml` prints the table and exits 0 (positional ignored)
- [x] `ymx --errors --test` → CLI usage error, exit 2
- [x] `ymx --errors -c 'main: 1'` → CLI usage error, exit 2
- [x] `ymx --help` lists `--errors` in the Options section
- [x] Table includes all codes E001–E016 (excluding E014 which is intentionally absent)
