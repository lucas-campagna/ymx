description: |
  Eliminate the ambiguous bare-$name component fallback from rule 2. Previously
  `$name` resolved to: (a) argument in scope, (b) component call with no args,
  (c) E003. Now `$name` resolves only to argument lookup; a missing argument is
  E003. To call a component without arguments, always use `$name()`. This removes
  the ambiguity between `$comp` as "pass argument" vs "call component".
