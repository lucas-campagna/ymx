  Implement `ymx --watch <path>`: a file/directory watcher that re-runs the
  full compile pipeline (load -> extract -> compile -> emit) on every change
  to a .yml/.yaml file under the watched path. Runs until interrupted.
  Mutually exclusive with --test (CLI usage error). Output goes to stdout
  or --output on every successful compile; diagnostics go to stderr and
  watching continues.
