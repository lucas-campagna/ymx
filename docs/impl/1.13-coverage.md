description: |
  LLVM source-based code coverage via `cargo-llvm-cov` (a wrapper over rustc
  `-C instrument-coverage`). `.github/workflows/coverage.yml` installs
  `cargo-llvm-cov` via `taiki-e/install-action`, runs
  `cargo llvm-cov --workspace --codecov --output-path codecov.json`, and
  uploads with `codecov/codecov-action@v5`, producing region/line/function
  coverage per file and per PR-diff. While the repo has no remote (and thus no
  Codecov account/token), the workflow instead exports
  `--lcov --output-path lcov.info` as a downloadable artifact so coverage is
  still produced without a token; the codecov.json path is commented-in once
  a remote + `CODECOV_TOKEN` exist. Lands after milestone 1.9 so the `_test`
  scenario harness produces real coverage across resolver rules 1–16 (a
  near-zero coverage number at scaffolding time is not worth gating).
