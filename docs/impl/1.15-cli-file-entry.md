# 1.15 — CLI file-based entry refactor

## Tasks

- [x] `args.rs`: `ParsedCli.path` documented as a **file**; `ParsedCli.entry` documented as a **bare component name** (default `main`)
- [x] `args.rs`: `ParsedCli::overrides()` constructs the 2-segment entry from `self.path.file_stem()` + `self.entry.as_deref().unwrap_or("main")` and passes it as `Some(entry)` into `CliOverrides.entry` (never `None` from the CLI)
- [x] `args.rs`: update unit tests — `cli_of(&["proj/"])` → `cli_of(&["proj/main.yml"])`; `--entry a.b.c` → `--entry foo`; `overrides()` asserts the constructed entry
- [x] `run.rs`: derive project root from `cli.path.parent()` (fallback to `""` for bare `main.yml`); call `load_project(project_root)`
- [x] `run.rs`: update unit tests — `cli_for(root)` → `cli_for(root.join("main.yml"))`; `cli_with_entry(root, "a.b.x")` → `cli_with_entry(root.join("a/b.yml"), "x")`
- [x] `help.rs`: synopsis `ymx <file> [flags]`; `<file>` = file to compile; `--entry <component>` = component within `<file>` (default `main`); project root = file's parent
- [x] `tests/cli.rs` (if present): update binary invocations to pass file paths
- [x] `cargo fmt && cargo clippy --workspace --all-targets && cargo test --workspace` clean

## Acceptance

- [x] `ymx proj/main.yml` compiles `main.main` (project root `proj/`)
- [x] `ymx proj/a/b.yml --entry x` compiles `b.x` (project root `proj/a/`)
- [x] `ymx bare.yml` compiles `main.main` (project root = CWD)
- [x] Missing file → E001 (load) exit non-zero; missing component in file → E009 exit non-zero
- [x] All existing CLI flag behavior (`--pretty`, `--format`, `--output`, `--plain`, `--test`, etc.) unchanged
