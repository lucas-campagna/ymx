title: "Literal HTML tag syntax"
short: "Angle-bracket `<name>` syntax for literal HTML tags in `from:` and shorthand keys"
description: |
  Introduces the `<name>` literal tag syntax: `from: <main>` produces the
  `<main>` HTML tag instead of dispatching to the `main` component. Also
  supports the shorthand `<name>: value` key form. Solves the collision between
  component names and HTML tag names (e.g. `main`).
status: done
depends_on: ["1.35"]
tags: [html, resolver, milestone]

## Tasks

### 1. Resolver: skip dispatch for `<name>` from-values

- [x] `crates/ymx-core/src/resolve.rs` — in `resolve_from_target`, detect `<name>` pattern (starts with `<`, ends with `>`) and return `Ok(None)` early, before `resolve_ref`
- [x] This makes `<name>` a plain forwarded property, same as an invalid `from` target
- [x] The rule-8 shortcut is naturally suppressed (shortcut won't match `<name>` either)

### 2. HTML Renderer: `<name>` shorthand tag key

- [x] `crates/ymx-core/src/render.rs` — in `find_tag_shortcut`, when the matched key matches `<name>` pattern (starts with `<`, ends with `>`), construct `{from: "<name>", children: <value>}` instead of using the value directly
- [x] Verify `render_tag` already handles `<name>` strings as tag names (it should — it just uses the string)
