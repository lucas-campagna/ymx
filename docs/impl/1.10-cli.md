# 1.10 — CLI (ymx-cli)

## Tasks

- [x] Arg parser (hand-rolled or `clap`; check 1.1 deps)
  - [x] `ymx <path> [flags]`; `<path>` = project root
  - [x] `--entry <path>` (default `main.main`)
  - [x] `--from-keyword <kw>`, `--default-keyword <kw>`, `--max-depth <n>`, `--pretty`, `--format <json|diagnostics>`, `--output <file>`
  - [x] `--plain`, `--plain-template` — mutually exclusive (CLI arg error, exit non-zero, no load)
  - [x] `--test`
- [x] Build `CliOverrides` from parsed args (None where absent)
- [x] Orchestration
  - [x] `load_project(path)?` -> `Project` (any diagnostic -> render all -> exit non-zero)
  - [x] `extract_options(&project, &cli)?` -> `Options` (entry resolved here; E009/E010 -> render -> exit non-zero)
  - [x] If `--test`: `run_tests(&project, &opts)`; print `PASS`/`FAIL` per test (+ diff on failure); exit non-zero if any fail or any `_test` parse error
  - [x] Else `compile(&project, &opts)` -> `Value`
- [x] Emit
  - [x] `format=Json`: serialize `Value` (pretty iff `--pretty`) to stdout, or to `--output <file>` (written only on success; on any diagnostic exit non-zero WITHOUT creating the file)
  - [x] `format=Diagnostics`: on success stdout empty, exit 0; diagnostics to stderr
  - [x] Diagnostics rendered `[code] file:line:col (component): message` to stderr
- [x] Exit codes: `0` success; `1` (default non-zero) on any diagnostic or test failure
- [x] Manual page / `--help` text consistent with flags

## Acceptance
- [x] `ymx proj/` compiles `main.main` and prints JSON; `--pretty` reformats
- [x] `--entry a.b.c` selects `a/b.yml`+`c`; ambiguous stem -> E009 exit non-zero
- [x] `--output out.json` creates file only on success; on error no file
- [x] `--test` runs scenarios, prints PASS/FAIL, exits non-zero on failure
- [x] `--plain` + `--plain-template` together -> CLI error (exit non-zero, no compile)
- [x] `--format diagnostics` on success: empty stdout, exit 0
