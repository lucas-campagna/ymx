# 1.16 — Entry component optionality (E009/E002 split)

## Context

The entry conflates two distinct concerns that were previously checked together
in `resolve_entry`:
1. **Entry file** — the document that supplies `_ymx` front matter. Must exist
   and be locatable (E009 at option-resolution: malformed path, missing file,
   ambiguous stem, non-component name).
2. **Entry component** — the default compile target. Only needed when something
   actually compiles it; if missing at that point, surfaces as E002, consistent
   with any other unknown component reference.

`ymx_config::extract_options` calls `resolve_entry` to find the front-matter
source file but discards the namespace and component — the component existence
check was unnecessary. `ymx_test::parse_tests` called `resolve_entry` upfront and
bailed entirely on failure, even though the entry target is only needed for
bare-A/B tests. The `compile` convenience already had an E002 fallback for a
missing entry component (dead code until now).
