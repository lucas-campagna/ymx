# Milestone 2.1 — TypeScript/WASM Library

## Overview

Build `ymx-web` as a native JavaScript/TypeScript library via WebAssembly. The
crate wraps `ymx-core` (which is already I/O-free and WASM-compatible) with
`wasm-bindgen` to expose a first-class JS API:

- `new YMX()` — instantiate the library
- `s.parse(code)` — parse a YAML string; subsequent calls overwrite previously
  defined components with the same name
- `s.my_comp({a: 1, b: 2})` — call a component with named arguments
- `s.my_comp(1, 2)` — call a component with positional arguments
- `${...}` math/context expressions evaluate in JavaScript (e.g.
  `select$: document.querySelector($0)` → calling `s.select('#my-button')`
  runs `document.querySelector('#my-button')` in the browser)
- Only the last-line result is returned from compilation

## Acceptance criteria

- `new YMX().parse(code)` parses YAML and stores components in-memory
- Subsequent `parse()` calls overwrite previous components with the same name
- `s.my_comp({a: 1, b: 2})` calls the component with named arguments forwarded
- `s.my_comp(1, 2)` calls the component with positional arguments forwarded
- `${document.querySelector($0)}` in YAML + `s.select('#btn')` evaluates
  `document.querySelector('#btn')` in the JavaScript context
- Only the last-line result is returned from compilation (no full output stream)
- Package builds with `wasm-pack build --target web` and is usable from
  TypeScript/JavaScript via ESM import
- TypeScript `.d.ts` file is generated or manually authored with correct types
