# 1.8 — Builtins: $merge / $map / $reduce

## Tasks

- [x] `Builtin` trait with per-builtin arg-evaluation strategy (special forms)
- [x] Reserved names: `map`/`reduce`/`merge` effective identifiers rejected (E007) at load (already in 1.3); builtins invoked only as `$map`/`$reduce`/`$merge`
- [x] `$merge(a, b)` — eager both args
  - [x] Array⊕Array -> concatenation; Object⊕Object -> shallow merge (later overwrites earlier)
  - [x] Any other shape (Array⊕Object, scalar where collection required) -> E011
- [x] `$map(fn, arr)` — first arg unevaluated callable (bare id, dotted ns path allowed: `$map(subdir.fn, b)`); second arg eager array
  - [x] Non-array 2nd arg -> E011; empty -> empty array
  - [x] Item binding: object -> named args; scalar -> `$0`; array item -> E011
- [x] `$reduce(fn, arr)` — like `$map` + `$last`
  - [x] Empty array -> `Value::Null` (no step run)
  - [x] One-element array -> runs single step, `last` NEVER in scope (ref -> E003)
  - [x] Subsequent steps: `$last` = previous resolved result; `last` in math subject to String re-scan
- [x] Arg references per rule 2/3/7 (bare `$name`, `$name(...)`, `${...}`)
- [x] Unit tests: rule-15 array+object examples; rule-16 `$map` example -> `["1 + 2","2 + 3"]`; `$reduce` example -> `"1 + 2 = 3"`; E011 bad 2nd arg; E011 mixed-shape merge; scalar item binds `$0`

## Acceptance
- [x] All rule-15/16 PRD examples reproduce
- [x] `$reduce([], …)` == `Null`
- [x] `$reduce` over one elem: referencing `last` -> E003
