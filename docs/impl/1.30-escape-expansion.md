  Preprocess `-c` values and stdin-as-script content to expand escape sequences
  (\\n → newline, \\t → tab, \\\\ → literal backslash) before YAML parsing.
  This lets users write multi-line YAML in single-quoted shell strings.
  stdin-as-args (JSON/YAML) is unaffected — JSON handles escapes natively.
