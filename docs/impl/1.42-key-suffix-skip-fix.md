  `x$sh`). These keys don't end with `?`, `?$`, or `$`, so the skip

  spurious property entries. The fix adds has_executor_suffix / has_key_suffix
  / contains("?$") checks to the skip condition.

# 1.42 — Fix key-suffix skip bug in resolve_property_set

## Task

Update the skip condition in the second loop of `resolve_property_set`
(`resolve.rs` ~line 1808) to also check `has_executor_suffix(name)`,
`has_key_suffix(name)`, and `name.contains("?$")`, catching all modifier
patterns handled by the first loop.
