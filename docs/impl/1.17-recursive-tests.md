title: "Recursive test discovery (ymx --test <dir>)"
short: "ymx --test on a directory recursively discovers and runs all project tests"
description: |
  Allow `ymx --test` (defaults to `.`), `ymx --test <dir>`, or `ymx --test <file>`
  to run tests. When a directory is given (or `.` is implied), walk it recursively,
  treat each subdirectory containing `.yml`/`.yaml` files as an independent project,
  run its tests, and aggregate results. When a file is given, run tests for that
  single project (existing behaviour). Exit 0 only if all tests across all projects
  pass. A project that fails to load is skipped with a warning.
status: planned

# 1.17 — Recursive test discovery

## Tasks

- [x] `args.rs`: make positional optional when `--test` is present (default `"."` when absent). Add `test_dir: Option<PathBuf>` to `ParsedCli` — set when `--test` is given and the resolved path is a directory at parse time (None = single-project file mode)
- [x] `run.rs`: when `cli.test_dir` is `Some(dir)` — walk `dir` recursively, find all subdirectories containing `.yml`/`.yaml` (each is a project root), run `load_project` → `extract_options` → `parse_tests` + `run_tests` per project, aggregate results; print `PASS/FAIL <relpath>: <target>` per test and a summary line; exit 0 only if all tests pass; skip (warn) on load failure
- [x] `help.rs`: update CLI usage to `ymx [path] [flags]` and document that `--test` defaults to `.` when path is omitted
- [x] `docs/PRD.md`: update CLI § to reflect optional positional with `--test` defaulting to `.`; add `test_dir: Option<PathBuf>` to `ParsedCli` in library API section
- [x] `crate tests`: add tests for the new recursive mode (single project in subdir, multiple projects, load-failure skip, exit code aggregation)
- [x] Run gatekeeper: `cargo fmt --check && cargo clippy --workspace --all-targets && cargo test --workspace`

## Acceptance
- [x] `ymx --test` (no path) runs all tests recursively from `.`
- [x] `ymx --test ./tests` runs all tests recursively from `./tests`
- [x] `ymx --test main.yml` runs tests for single project (existing behaviour unchanged)
- [x] `ymx --test ./nonexistent` skips/warns and exits 0 if no other projects
- [x] `ymx --test ./a ./b` errors (too many positionals — still exactly 1 positional allowed)
- [x] Exit code 0 only when all tests across all projects pass
