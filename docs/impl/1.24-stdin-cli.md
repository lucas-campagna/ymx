# 1.24 — CLI stdin support

## Tasks

- [x] `args.rs`: detect terminal stdin (usage error exit 2). Allow 0 positionals
  (stdin-as-script mode). With positional present, mark args-from-stdin mode.
- [x] `run.rs` — no-positional branch: read all stdin as UTF-8 YAML string →
  create temp project directory (e.g. `std::env::temp_dir()/ymx-stdin-<nonce>/`)
  → write `main.yml` → proceed with normal `load_project → extract_options →
  compile` pipeline → clean up temp dir (success or failure/panic via Drop).
- [x] `run.rs` — args-from-stdin branch: read stdin → try
  `serde_json::from_reader` → on parse failure retry with `YamlLoader` →
  convert resulting `Value` to `Args`: `Object` → `Args::Named(sorted)`,
  `Array` → `Args::Positional`, scalar → `Args::Positional([value])` →
  call `compile_component(project, "<entry>", &args, &opts)` instead of
  `compile`.
- [x] `Value → Args` conversion helper (pure, no I/O).
- [x] Terminal guard: if stdin is a tty in either mode, exit 2 with usage error.
- [x] Unit tests: stdin args parsing, JSON/YAML auto-detect, Value→Args
  conversion, tty-detection guards, temp-file cleanup.
- [x] `cargo fmt && cargo clippy --workspace --all-targets` clean.

## Acceptance

- [x] `cat script.yml | ymx` compiles `main.main` from stdin YAML — equivalent to `ymx script.yml`
- [x] `echo '{"a":123}' | ymx script.yml` calls `main` with `a=123`
- [x] `echo '[1,2,3]' | ymx script.yml` calls `main` with `$0=[1,2,3]`
- [x] YAML stdin args work when JSON parse fails: `echo 'x: 1' | ymx script.yml` calls `main` with `x=1`
- [x] `ymx script.yml` with a terminal stdin exits 2 (usage error)
- [x] `ymx` with a terminal stdin exits 2 (usage error)
- [x] `ymx --test .` is unchanged (stdin not used)
- [x] Temp directory is cleaned up on success, error, and panic
