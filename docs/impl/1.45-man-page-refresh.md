# 1.45 — Man page & docs refresh

## Problem

The `ymx.1` man page (at `crates/ymx-cli/man/ymx.1`) was written for v1.0–v1.18
and has not been updated since. It is missing coverage of:

- `_use` directive (v1.25, v1.38) — the entire multi-file import system
- Rules 19–22 (v1.27, v1.35, v1.42–1.43, v1.39) — shell, HTML, IPC, brace calls
- CLI flags added after v1.18: `-c`, `--plain`, `--plain-template`, `--no-exec`,
  `--allowed-backends`, `--no-ipc`, `--allowed-ipc`, `--errors`
- `_ymx` front-matter fields: `allowed_backends`, `allowed_ipc`, `plain`
- Diagnostic codes E016, E017, E018
- Examples for multi-file projects, `-c`, shell commands, IPC, HTML

## Tasks

### Task 1: Add `_use` section to man page

- [ ] Add a new `.SH "MULTI-FILE PROJECTS"` section between `.SH DESCRIPTION` and `.SH OPTIONS`
- [ ] Document the three `_use` forms:
  - Bare `*` (recursive wildcard, default when no `_use` present)
  - Wildcard object `{"*": "file"}` (import all public components from file)
  - Named entries `{alias: "file.component"}` (import specific component under alias)
- [ ] Document transitive re-export: imported file's own `_use` is processed first; imported names are re-exportable
- [ ] Document file-scoped components (`_`-prefixed) cannot be imported (E005)
- [ ] Document cycle detection (E001)
- [ ] Document IPC declarations: mapping RHS (not string) = IPC component (rule 21)
- [ ] Add examples for each form

### Task 2: Add rules 19–22 to man page

- [ ] Add `.SS "Rule 19 — Shell components (sh, pw)"` under `.SH RULES`
  - `$sh{cmd}` / `$pw{cmd}` value expressions
  - Property-key shorthand: `main$sh: cmd`
  - `allowed_backends` restriction
  - Result shape: `{exit_code, stdout}`
  - E016 for execution errors
- [ ] Add `.SS "Rule 20 — HTML renderer"`
  - `from` property for tag selection
  - `children` shape (scalar, object with `from`, null)
  - Literal tag syntax: `from: <name>`
  - Shorthand: `<name>: value`
  - `class`/`style` normalization
  - E017 for array/object children without `from`
- [ ] Add `.SS "Rule 21 — External components via _use IPC declarations"`
  - Mapping RHS in `_use` = IPC component
  - Config reference tables (runner, transport, protocol, request shaping, response mapping, HTTP shaping, timeouts, lifecycle hooks)
  - Wire format: `mode: text` vs `mode: json`
  - Session lifetime
  - E018 for IPC call failures
- [ ] Add `.SS "Rule 22 — Brace calls and the $<name> key suffix"`
  - `$name{payload}` syntax
  - Payload grammar (scalar, object, array, empty)
  - Key suffix: `key$name: value`
  - Equivalences with `from` and shortcut forms
