## 1. ymx-core: PdfBackend trait + system/bundled impls

- [x] `crates/ymx-core/src/render.rs` — add `PdfBackend` trait: `fn render(&self, html: &str) -> Result<Vec<u8>, PdfError>`
- [x] `PdfError` struct: `pub struct PdfError { pub message: String }`
- [x] `SystemChromeBackend` struct — uses `html2pdf` with `headless_chrome` (no fetch feature)
- [x] `BundledChromeBackend` struct — uses `html2pdf` with `headless_chrome/fetch` (auto-downloads Chromium)
- [x] Both impls: `render(&self, html: &str)` → `Result<Vec<u8>, PdfError>`
- [x] Feature gates in `crates/ymx-core/Cargo.toml`:
  ```toml
  [features]
  default = ["pdf-system"]
  pdf-system  = []
  pdf-bundled = ["fetch"]
  ```
  (html2pdf enabled via both features; the distinction is the headless_chrome fetch feature)
- [x] Re-export `PdfBackend`, `SystemChromeBackend`, `BundledChromeBackend`, `PdfError` from `crates/ymx-core/src/lib.rs`
- [x] Note: ymx-core stays I/O-free — trait takes `&str`, returns `Vec<u8>`

## 2. ymx-core: Add Format::Pdf variant

- [x] `crates/ymx-core/src/project.rs` — add `Pdf` to the `Format` enum alongside `Json`, `Html`, `Diagnostics`

## 3. ymx-cli: PdfBackend selection + emit()

- [x] `crates/ymx-cli/src/run.rs` — `emit_pdf()` function that:
  - Takes `Value`, `Format::Pdf`, and a `dyn PdfBackend` reference
  - Calls `DefaultHtmlRenderer.render_html(&value)` to get HTML string
  - Calls `backend.render(&html)` to get PDF bytes
  - Writes bytes to output (file or stdout)
- [x] `crates/ymx-cli/src/args.rs` — add `--pdf-backend <system|bundled|docker>` argument (string enum, default "system")
- [x] Wire the backend selection: match `args.pdf_backend` → construct `SystemChromeBackend`, `BundledChromeBackend`, or `DockerChromeBackend`

## 4. ymx-cli: DockerChromeBackend implementation

- [x] `render_pdf_docker()` in `crates/ymx-cli/src/run.rs` — writes HTML to index.html, runs docker command, reads convert.pdf, cleans up
- [x] Docker command: `docker run --rm -v $(pwd):/data/ -w /data/ pdfix/html-to-pdf:latest html-to-pdf -i index.html -o convert.pdf`
- [x] Feature gate in `crates/ymx-cli/Cargo.toml`: `pdf-docker = []`
- [x] When `--pdf-backend docker` is selected but Docker is not available, return a helpful error message

## 5. ymx-cli: `_ymx.pdf_backend` front-matter support
