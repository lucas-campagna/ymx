# `_use` transitive re-export

## Problem

When `transitive.yml` has `_use: {one: "mid.middle"}` and `mid.yml` has
`_use: {middle: "leaf.deep"}`, the import fails with E002 — `middle` is not
visible in `mid.yml`'s namespace because mid's own `_use`-imported names are
not re-exported.

## Solution

In `ymx-lib`'s `load_project` (or `resolve_use_graph`), after processing a
file's `_use` directive and resolving its own imports, the imported names
must be registered in that file's namespace **before** the file is consumed
by its caller. This means:

1. When processing `_use` for file B, resolve B's own imports first.
2. Register B's imported names in B's namespace.
3. When file A imports `B.name`, look up `name` in B's namespace (which now
   includes B's `_use`-imported names).
