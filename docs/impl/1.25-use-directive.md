# 1.25 — `_use` directive (explicit file imports)

## Tasks

- [x] `ymx-core`: extend `extract_document` to collect a new `RawMetaUse` variant.
  The three forms: bare `*` (wildcard signal), string `"*"` (same), and object
  mapping (alias → "file.component"). Invalid RHS syntax = E010.
- [x] `ymx-lib`: implement `_use` resolution instead of automatic recursive walk.
  Build the import graph (DFS from entry file), topologically sort, detect cycles
  (E001). Each node in the graph is a file to load.
- [x] Named import: resolve `<file>.<component>` RHS — file stem resolves to exactly
  one .yml/.yaml (E009 on ambiguity/missing), component must exist (E002).
  Register in global namespace under the alias. File-scoped components → E005.
- [x] Wildcard `*`: load target file, register all public components/templates
  with their original names in the global namespace.
- [x] Bare `*`: recursive walk of the importing file's directory — same filter
  rules as the old walk() (skip .git, hidden, subdirs with no YAML directly).
- [x] `ymx-lib`: remove automatic recursive `walk()` at project root — no implicit
  loading. `load_project` now takes the entry file path and resolves its _use
  graph.
- [x] `ymx-lib`: change `load_project(root: &Path)` — the root is now the entry
  file's parent, but loading is driven by the _use graph. If the entry has no
  _use, treat as _use: *.
- [x] Error codes: E001 (cycle in _use graph), E002 (unknown imported component),
  E005 (imported a file-scoped component), E009 (target file not found or
  ambiguous).
- [x] Unit tests: all _use forms, transitive imports, cycles, file-scoped
  rejection, E009/E002/E005 cases, backward compat (_use absent = * behavior).
- [x] `cargo fmt && cargo clippy --workspace --all-targets` clean.

## Acceptance

- [x] `_use: *` on entry = recursive walk of entry's directory (backward compat)
- [x] `_use: {"*": "foo"}` imports all from foo.yml into global namespace
- [x] `_use: {x: "foo.bar"}` imports bar from foo.yml as x (E002 if missing)
- [x] `_use: {x: "foo._bar"}` → E005 (file-scoped not importable)
- [x] `A imports B, B imports C` → components from C available in A
- [x] `A imports B, B imports A` → E001
- [x] `foo.yml` and `foo.yaml` both present → E009
- [x] Entry file's directory has no YAML files directly → walk finds nothing
  (empty project, compile succeeds if component exists)
